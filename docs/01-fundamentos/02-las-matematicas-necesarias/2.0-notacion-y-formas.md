# 2.0 Notación y formas: las dimensiones en Deep Learning

> **La intuición fundamental:** El 80 % de los errores al programar redes neuronales no son fallos matemáticos complejos, sino **desajustes de dimensiones (*shape mismatches*)**. Visualizar la "forma" de los tensores a lo largo del grafo de cómputo es el mapa mental más importante para depurar cualquier arquitectura.

---

## 📐 Jerarquía de Tensores: de escalar a n-dimensiones

| Objeto Matemático | Rango (Rank / Ndim) | Notación Típica | Ejemplo en Código (PyTorch/NumPy) | Ejemplo Físico / Aplicación |
|---|---|---|---|---|
| **Escalar** | 0 | $x \in \mathbb{R}$ | `torch.tensor(3.14)` | Valor de pérdida (*loss*), Tasa de aprendizaje |
| **Vector** | 1 | $\mathbf{x} \in \mathbb{R}^d$ | `torch.zeros(512)` | *Embedding* de una palabra, vector de sesgos $b$ |
| **Matriz** | 2 | $\mathbf{W} \in \mathbb{R}^{m \times n}$ | `torch.randn(768, 512)` | Matriz de pesos de una capa lineal |
| **Tensor 3D** | 3 | $\mathbf{X} \in \mathbb{R}^{B \times L \times D}$ | `torch.randn(32, 128, 768)` | Lote de secuencias de texto: `(Batch, Seq_Len, Dim)` |
| **Tensor 4D** | 4 | $\mathbf{X} \in \mathbb{R}^{B \times C \times H \times W}$ | `torch.randn(64, 3, 224, 224)` | Lote de imágenes (PyTorch): `(Batch, Channels, Height, Width)` |
| **Tensor 5D** | 5 | $\mathbf{X} \in \mathbb{R}^{B \times C \times T \times H \times W}$ | `torch.randn(8, 3, 16, 224, 224)` | Lote de vídeos: `(Batch, Channels, Frames, Height, Width)` |

## 🏷️ Convenciones de formas habituales (*Shape Conventions*)

En el ecosistema moderno (PyTorch, HuggingFace, JAX) existen normas no escritas para nombrar las dimensiones:

```none
Texto / Transformers:    (B, L, D)  ──▶  Batch size, Sequence Length, Embedding Dimension
Imágenes (CNN PyTorch):  (B, C, H, W) ──▶  Batch size, Channels, Height, Width
Imágenes (TensorFlow):   (B, H, W, C) ──▶  Batch size, Height, Width, Channels
Atención Multi-Cabeza:   (B, H, L, d_k) ──▶ Batch, Heads, Sequence Length, Head Dimension
```

---

## ⚡ Reglas de Transmisión (*Broadcasting*)

El *broadcasting* permite operar tensores de distintas formas sin copiar datos en memoria. La regla se aplica **de derecha a izquierda**:

1. Si las dimensiones no tienen la misma cantidad de ejes, se añaden ejes de tamaño `1` a la izquierda del tensor más pequeño.
2. Dos dimensiones son compatibles si son **iguales** o si **una de ellas es 1**.

```none
Tensor A:  (32, 1, 768)
Tensor B:     (128, 768)  ──▶ se expande implícitamente a (1, 128, 768)
------------------------
Resultado: (32, 128, 768)
```

> **Atención al error silencioso:** Si intentas restar dos vectores de forma `(N,)` y `(N, 1)`, el broadcasting creará una matriz `(N, N)` sin dar error, consumiendo memoria y cambiando la lógica de la operación.

## 🔀 Notación de Einstein (`einsum`)

`einsum` es el estándar oro para expresar operaciones matriciales y de tensores complejas de forma limpia y transparente:

| Operación Matemático | Código Tradicional (PyTorch) | Notación `einsum` |
|---|---|---|
| Producto Escalar | `torch.dot(a, b)` | `torch.einsum('i,i->', a, b)` |
| Multiplicación Matriz-Vector | `torch.matmul(A, x)` | `torch.einsum('ij,j->i', A, x)` |
| Multiplicación de Matrices | `A @ B` | `torch.einsum('ij,jk->ik', A, B)` |
| Traza de una Matriz | `torch.trace(A)` | `torch.einsum('ii->', A)` |
| Atención Multi-Cabeza ($Q \cdot K^T$) | `torch.matmul(Q, K.transpose(-1, -2))` | `torch.einsum('bhld,bhmd->bhlm', Q, K)` |
| Transposición de Lote | `x.permute(0, 2, 1)` | `torch.einsum('bld->bdl', x)` |
