# 3.3 Pérdidas y optimizadores

> **Qué responde:** ¿cómo se mide el error y cómo se traduce en una corrección?

## La pérdida es la definición del objetivo

Si la pérdida está mal elegida, el modelo optimizará algo que no querías. Y
recuerda: toda pérdida es una verosimilitud disfrazada (→ 2.3).

| Tarea | Pérdida habitual |
|---|---|
| Regresión | MSE · MAE · Huber (robusta a outliers) |
| Clasificación | Entropía cruzada · BCE · focal loss (desbalanceo) |
| Comparar / recuperar | Contrastivas: InfoNCE, triplet |
| Generar | ELBO (VAE) · adversarial (GAN) · score matching (difusión) |
| Alinear | De preferencia: Bradley-Terry, DPO |

## La familia de optimizadores

```none
SGD
 ├─► + Momentum ──► + Nesterov
 ├─► Adaptativos: AdaGrad ──► RMSProp ──► Adam (2014)
 │                                          └─► AdamW ★ el estándar actual
 ├─► Segundo orden aproximado: K-FAC · Shampoo · Muon
 └─► Especializados: LAMB (lotes enormes) · Adafactor (memoria) · Lion
```

**AdamW** es lo que usarás por defecto. La "W" es el *weight decay desacoplado*:
aplicar la penalización de pesos aparte del gradiente adaptativo. La diferencia
frente a Adam clásico es medible y real.

**Coste oculto:** el optimizador guarda 2 tensores extra por parámetro. Un
modelo de 1 GB de pesos necesita ~3 GB solo para entrenar.

## El hiperparámetro número 1: la tasa de aprendizaje

Cuánto de grande es cada paso. **Ajústala antes que nada.**

- **Warmup** — subirla gradualmente al principio. Imprescindible en Transformers.
- **Decaimiento** — bajarla al final (cosine, step, lineal).
- **LR range test** — barrido rápido para encontrar el rango útil.
- **Relación con el lote** — al doblar el lote, la regla habitual es doblar la
  tasa (escalado lineal) o multiplicarla por √2.

## Recorte de gradiente (clipping)

Poner un techo a la norma del gradiente. Barato y evita que un lote raro
destruya el entrenamiento.

## Buscar hiperparámetros

A mano < aleatorio < bayesiano (Optuna) < bandits (ASHA, Hyperband). Y siempre
la tasa de aprendizaje primero: mueve más que todo lo demás junto.
