# Atajos de JupyterLab

| Atajo | Acción |
|---|---|
| ++esc++ / ++enter++ | Modo comando / edición |
| ++a++ / ++b++ | Insertar celda arriba / abajo |
| ++d++ ++d++ | Borrar celda |
| ++shift+enter++ | Ejecutar y avanzar |
| ++shift+m++ | Fusionar celdas seleccionadas |
| ++i++ ++i++ | Interrumpir el kernel |
| ++0++ ++0++ | Reiniciar el kernel |

Primeras líneas útiles en cualquier notebook del laboratorio:

