# 5.3 Redes neuronales: la historia

> **Cómo leer esta sección:** cada arquitectura existe porque la anterior chocó
> contra un muro. El muro es la explicación.

```none
Perceptrón (1958)
   │  muro: no resuelve XOR
   ▼
MLP + backprop (1986)
   │  muro: no escala a imágenes; no entiende la posición
   ▼
CNN ──────────────────────► visión
   │  muro: tamaño fijo, no sirve para secuencias
   ▼
RNN
   │  muro: el gradiente muere en el tiempo
   ▼
LSTM / GRU (1997)
   │  muro: todo el significado en un solo vector (seq2seq)
   ▼
Atención (2014)
   │  muro: la recurrencia impide paralelizar
   ▼
TRANSFORMER (2017) ───────► lenguaje, y luego TODO
   │
   ├─► escala: modelos gigantes (5.3.7)
   │
   └─ ramas paralelas, no derivadas:
       ├─► generativos: VAE · GAN · difusión (5.3.5)
       └─► grafos y simetrías (5.3.6)
```

## Los dos inviernos

- **1969–1980** — Minsky y Papert demuestran el límite del perceptrón. Se corta
  la financiación.
- **1998–2012** — las redes profundas *no entrenaban*: ganaban SVM y boosting.
  Se desbloquea con ReLU + dropout + GPU + ImageNet.

**El deep learning moderno empieza en 2012 (AlexNet), no en 1986.**

## Las dos ramas que no son secuencia

Los modelos generativos (5.3.5) y las redes sobre grafos (5.3.6) **no
descienden** del Transformer: son respuestas a preguntas distintas que se
desarrollaron en paralelo y convergieron después.
