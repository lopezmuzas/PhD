# 5.4 Redes neuronales: la historia

> **Cómo leer esta sección:** Cada arquitectura existe porque la anterior chocó contra un muro. El muro es la explicación.

```none
Perceptrón (1958)
   │  muro: no resuelve XOR
   ▼
MLP + backprop (1986)
   │  muro: no escala a imágenes; no entiende la posición
   ▼
CNN ──────────────────────► visión (5.4.2)
   │  muro: tamaño fijo, no sirve para secuencias
   ▼
RNN
   │  muro: el gradiente muere en el tiempo
   ▼
LSTM / GRU (1997) ───────► secuencias (5.4.3)
   │  muro: todo el significado en un solo vector (seq2seq)
   ▼
Atención (2014)
   │  muro: la recurrencia impide paralelizar
   ▼
TRANSFORMER (2017) ───────► lenguaje, y luego TODO (5.4.4)
   │
   ├─► escala: modelos gigantes (5.4.7)
   │
   └─ ramas paralelas, no derivadas:
       ├─► generativos: VAE · GAN · difusión (5.4.5)
       └─► grafos y simetrías (5.4.6)
```

---

## ❄️ Los Dos Inviernos del Deep Learning

- **1969–1980**: Minsky y Papert demuestran el límite del perceptrón simple (incapaz de resolver la función lógica XOR). Se corta drásticamente la financiación.
- **1998–2012**: Las redes profundas resultaban intratables de entrenar (*desvanecimiento del gradiente*); los modelos clásicos como SVM y Gradient Boosting (→ 5.2) ganaban de forma sistemática. El campo se desbloquea en 2012 con la combinación de **ReLU + Dropout + GPUs modernas + ImageNet (AlexNet)**.

> **El Deep Learning moderno empieza en 2012 (AlexNet), no en 1986.**
