# 4.8 El pipeline real: cómo se encadenan

> **La intuición fundamental:** Ningún sistema de Inteligencia Artificial moderno de vanguardia utiliza un único paradigma de forma aislada. Los sistemas reales **componen y encadenan múltiples fuentes de señal de aprendizaje en una secuencia estricta**, donde cada fase corrige los fallos estructurales de la anterior.

---

## ⛓️ El Pipeline Estándar de un Modelo de Fundación

```none
  [ Datos Crudos (Billones de tokens) ] ──▶ 1. Auto-supervisado (§4.3)  ──▶ Modelo Base (Capacidad / Conocimiento)
                                                    │
  [ Demostraciones de Calidad ] ──────────▶ 2. SFT / Imitación (§4.4)   ──▶ Modelo Instruido (Formato / Obediencia)
                                                    │
  [ Comparaciones Humano/IA ] ────────────▶ 3. Preferencias / DPO (§4.5) ──▶ Modelo Alineado (Tono / Seguridad)
                                                    │
  [ Tests / Verificadores ] ──────────────▶ 4. RL / RLVR (§4.6)        ──▶ Modelo Razonador (Pensamiento profundo)
                                                    │
  [ Modelo Maestro Grande ] ──────────────▶ 5. Destilación (§4.7)      ──▶ Modelo Desplegable (Rápido / Eficiente)
```

---

## 📊 Comparativa del Pipeline en Cada Fase

| Fase | Paradigma | Fuente de Señal | Tamaño del Dataset | Función Principal en el Sistema |
|---|---|---|---|---|
| **1. Preentrenamiento** | Auto-supervisado (§4.3) | El propio dato (siguiente token / máscara) | $10^{12} - 10^{13}$ tokens | Inyectar conocimiento del mundo, gramática y razonamiento latente. |
| **2. Fine-Tuning Supervisado (SFT)** | Imitación (§4.4) | Demostraciones de alta calidad $(x, y)$ | $10^4 - 10^5$ ejemplos | Adaptar la interfaz del modelo a responder preguntas y seguir instrucciones. |
| **3. Alineamiento** | Preferencias / DPO (§4.5) | Pares de preferencia $y_w \succ y_l$ | $10^4 - 10^5$ pares | Refinar el tono, eliminar sesgos/toxicidad y evitar respuestas evasivas. |
| **4. Razonamiento Avanzado** | RL / RLVR (§4.6) | Recompensas verificables ($R \in \{0, 1\}$) | $10^5 - 10^6$ problemas | Descubrir estrategias de razonamiento *Chain-of-Thought* autónomas. |
| **5. Despliegue** | Destilación (§4.7) | Logits / salidas del modelo de la fase 4 | Variable | Producir modelos compactos (1B–8B) aptos para ejecución local. |

---

## 💡 Por qué el Orden no es Negociable

1. **No puedes hacer SFT sin Preentrenamiento**: Sin las representaciones latentes ricas aprendidas en la fase auto-supervisada, el modelo simplemente memorizaría las demostraciones de SFT sin generalizar.
2. **No puedes hacer Preferencias (DPO/RLHF) sin SFT**: Un modelo base autoregresivo genera texto continuo sin estructura de diálogo; no se le puede pedir elegir entre dos "respuestas a una instrucción" si aún no sabe responder instrucciones.
3. **No puedes hacer RLVR sin una base razonablemente capaz**: Si la exploración aleatoria del modelo inicial nunca da por azar con una respuesta correcta ($R=0$ siempre), el gradiente de política no recibe señal alguna para aprender.

---

## ⚠️ Regla de Oro del Cómputo vs. Calidad de Datos

```none
  Cómputo Requerido:         Preentrenamiento (99 %) ──▶ RLVR (0.9 %) ──▶ SFT / DPO (0.1 %)
  Calidad de Datos Exigida:  Preentrenamiento (Media) ──▶ SFT (Extrema) ──▶ Preferencias (Muy Alta)
```

> **Conclusión:** Cada fase subsiguiente requiere **órdenes de magnitud menos datos**, pero exige una **calidad y limpieza de señal inmensamente mayor**.
