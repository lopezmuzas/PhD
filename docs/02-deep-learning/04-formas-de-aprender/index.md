# 4. Formas de aprender

> **Pregunta 1 de 3:** ¿de dónde sale la señal de aprendizaje?

Es lo que decide **qué necesitas tener** para entrenar: ¿etiquetas humanas?
¿solo datos crudos? ¿un entorno con el que interactuar?

| Forma | La señal viene de… | Coste |
|---|---|---|
| [Supervisado](4.1-con-etiquetas-supervisado.md) | Etiquetas humanas | Alto: etiquetar es caro |
| [Auto-supervisado](4.2-con-el-propio-dato-auto-supervisado.md) | El propio dato | Casi cero: la base de los modelos gigantes |
| [No supervisado](4.3-sin-etiquetas-no-supervisado.md) | Solo la estructura | Cero, pero el objetivo es difuso |
| [**Refuerzo**](4.4-por-prueba-y-error-refuerzo.md) ★ | Recompensas por interactuar | Muy alto: hace falta un entorno |
| [Mezclas](4.5-mezclas.md) | Combinaciones | Variable |

★ El refuerzo es la sección clave para este proyecto.
