# 4.5 Mezclas

> **La señal viene de:** combinaciones de las anteriores.

## Aprender imitando

**Behavioral cloning** — copiar demostraciones de un experto en vez de
descubrir por prueba y error. Es supervisión aplicada a un problema de control.
Barato y rápido, pero se degrada cuando el agente sale de las situaciones
demostradas.

**Inverse RL** — más ambicioso: inferir *cuál era la recompensa* que el experto
optimizaba, y luego optimizarla uno mismo.

## Aprender de preferencias humanas

Así se alinean los modelos de lenguaje:

```none
1. SFT ................ ajuste supervisado con ejemplos de buenas respuestas
2. Modelo de recompensa  humanos comparan pares → se entrena un predictor
3. Optimización ....... el modelo grande se ajusta contra esa recompensa (PPO)
```

**DPO** (2023) hace lo mismo sin RL explícito: optimiza la preferencia
directamente. Más simple y estable; se ha comido buena parte del terreno de
RLHF.

**IA constitucional / RLAIF** — el feedback lo genera el propio modelo bajo un
conjunto de principios escritos, reduciendo la necesidad de anotadores.

## Recompensa verificable (RLVR)

Cuando la solución se puede comprobar automáticamente (matemáticas, código,
demostraciones), no hacen falta humanos: la señal es "¿compila? ¿da el
resultado correcto?". Así se entrenan los modelos de razonamiento actuales
(DeepSeek-R1, 2025), con GRPO como algoritmo típico.

## El peligro común a todas

**Reward hacking**: el modelo optimiza la métrica destruyendo el objetivo real.
Es el fallo característico de aprender de una señal indirecta.
