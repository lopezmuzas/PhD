# 15.7 Cómo está montado (infraestructura y mantenimiento)

## Lo que hace falta

| Componente | Necesario para | Nota |
|---|---|---|
| Python 3.11+ | Todo | 3.12 va bien |
| `fastapi`, `uvicorn`, `httpx` | Shim, proxy, router, banco | ~30 MB |
| `jq` | Leer los registros JSONL | `apt install jq` |
| Docker + Compose | Despliegue reproducible | Opcional, pero coherente con el resto |
| Ollama | Autocompletado local y GGUF | ~4 GB con un modelo pequeño |
| PyTorch | [Lab 4](15.6-lab4-un-modelo-de-lenguaje-propio.md) | CPU vale; con GPU es 20-50× más rápido |
| GPU ≥ 8 GB VRAM | Solo para la variante LoRA | El modelo por caracteres no la necesita |
| Disco | Corpus, checkpoints y registros | ~10 GB holgados |

Puertos: `8000` shim del modelo propio, `8080` proxy y router, `11434` Ollama.
**Todo en `127.0.0.1`.** Un proxy con la clave dentro, expuesto a la red, es una
factura ajena esperando a ocurrir.

## Composición de servicios

```yaml
services:
  proxy:
    build: ./proxy
    ports: ["8080:8080"]
    env_file: .env
    volumes:
      - ./proxy/logs:/app/logs      # los registros sobreviven al contenedor
    restart: unless-stopped

  mi-modelo:
    build: ./mi-modelo
    ports: ["8000:8000"]
    volumes:
      - ./mi-modelo/checkpoints:/app/checkpoints
    profiles: ["modelo"]            # docker compose --profile modelo up
```

El perfil en `mi-modelo` sigue el mismo patrón que los perfiles CPU/GPU del
`dl-lab`: el servicio pesado no arranca salvo que se pida.

## Qué no va a git

```gitignore

mi-modelo/muestras/
bench/resultados/*.json
**/__pycache__/
```

Los registros del proxy contienen **el código fuente completo** que se envía a
los modelos. Ese directorio hereda la sensibilidad de lo que se haya escrito
mientras estaba encendido.

## Orden de montaje

1. **Configuración del editor con los gratuitos** ([15.1](15.1-el-editor-y-su-configuracion.md)). Media hora. Ya funciona algo.
2. **Proxy espía** ([15.3](15.3-lab1-el-proxy-espia.md)). Una tarde. Lo que más enseña por hora invertida.
3. **Banco de pruebas** ([15.5](15.5-lab3-el-banco-de-pruebas.md)). Una tarde. Da los números que sustituyen a las estimaciones.
4. **Router** ([15.4](15.4-lab2-el-router-propio.md)). Se apoya en lo anterior: sin registros no hay política que medir.
5. **Modelo propio** ([15.6](15.6-lab4-un-modelo-de-lenguaje-propio.md)). El más largo y el menos «útil», y el que más se parece al trabajo de tesis.

## El cuaderno

Una entrada por sesión, con el mismo esqueleto:

- **Pregunta** — qué quería averiguar hoy.
- **Montaje** — qué toqué, con la orden exacta.
- **Números** — latencias, pérdidas, costes, tamaños de contexto. Reales, no estimados.
- **Sorpresa** — qué esperaba que pasara y no pasó. Es la parte que luego vale.
- **Siguiente** — la pregunta que abre esto.

## Preguntas abiertas

- ¿Cuánto contexto inyecta el editor por su cuenta, y qué fracción es útil?
- ¿A partir de qué dificultad deja de compensar el modelo barato?
- ¿Cuánto se pierde al bajar de 5/5 a 4/5 en tareas reales, medido y no intuido?
- ¿Se puede **aprender** la política de enrutado en vez de escribirla? Suena a
  bandido contextual sobre registros pasados, y eso es RL offline (**→ 1.6**).

## Mantenimiento (lo que caduca)

| Cosa | Cada cuánto | Dónde |
|---|---|---|
| IDs de modelos `:free` | Semanal — la rotación es agresiva | `openrouter.ai/models`, filtro *Free* |
| Precios de los de pago | Mensual | Ficha del modelo en OpenRouter |
| IDs de NVIDIA NIM | Antes de usarlos | Ficha del modelo en `build.nvidia.com` |
| Cuotas de Google | Trimestral | `ai.google.dev/gemini-api/docs/rate-limits` |

Síntomas y causas:

| Error | Causa habitual |
|---|---|
| 404 | ID de modelo retirado del catálogo |
| 429 | Cuota agotada: cambiar de modelo o esperar al reinicio diario |
| 401 | Clave mal puesta, o `provider: openai` con una clave `sk-or-v1-` |

## Sobre la herramienta

Continue fue adquirida por Cursor en junio de 2026 y su repositorio pasó a solo
lectura, con la v2.0.0 como última versión de la extensión. Sigue funcionando,
pero no habrá más actualizaciones del equipo original. Alternativa activa con
configuración parecida: Cline.

Nada de lo montado aquí depende de esa decisión: shim, proxy, router y banco
hablan el protocolo de OpenAI, así que sobreviven al cambio de editor. Esa
independencia era, en parte, el motivo de montarlo así.
