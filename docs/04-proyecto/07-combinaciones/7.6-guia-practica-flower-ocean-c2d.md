# 7.5 Guía práctica: Flower + Ocean Protocol C2D

> **El objetivo de este manual:** Guía paso a paso para programar un pipeline de **Aprendizaje Federado** utilizando el framework [Flower (`flwrlabs/flower`)](https://github.com/flwrlabs/flower) ejecutado sobre la infraestructura **Compute-to-Data (C2D)** de **Ocean Protocol / Pontus-X**.

---

## 🏛️ Arquitectura del Pipeline Asíncrono (Zero-Trust)

Para entornos donde los proveedores de datos no permiten tráfico de red saliente arbitrario desde sus contenedores de cómputo, utilizaremos el **Patrón Asíncrono por Archivos (`/inputs` y `/outputs`)**:

```none
  Orquestador (ocean.py)                Ocean Provider (On-Premise)             Contenedor C2D (Docker / K8s)
 ─────────────────────────             ─────────────────────────────           ──────────────────────────────
 1. Publica θ_t en /inputs   ───▶      2. Monta /inputs y /data      ───▶      3. Arranca client_c2d.py
                                                                               4. Lee θ_t de /inputs
                                                                               5. Entrena localmente sobre /data
                                       7. Firma /outputs             ◄───      6. Escribe θ_t^k en /outputs
 8. Descarga θ_t^k          ◄───      (Remote Attestation)
 9. Aplica FedAvg ──▶ θ_{t+1}
```

## 💻 Paso 1: El Script del Cliente Flower (`client_c2d.py`)

Este script se ejecuta dentro del contenedor de C2D en el servidor del proveedor de datos. Lee los pesos de la ronda de `/inputs`, entrena sobre los datos montados en `/data`, y escribe la actualización en `/outputs`.

```python
import os
import json
import numpy as np
import torch
import torch.nn as nn
import torch.optim as optim
import flwr as fl

# 1. Definir la Arquitectura del Modelo Local (ej. MLP para regresión/clasificación)
class LocalModel(nn.Module):
    def __init__(self, input_dim=10, output_dim=2):
        super(LocalModel, self).__init__()
        self.fc = nn.Sequential(
            nn.Linear(input_dim, 64),
            nn.ReLU(),
            nn.Linear(64, output_dim)
        )
    def forward(self, x):
        return self.fc(x)

# 2. Cliente de Flower Adaptado a Entornos de Archivo C2D
class OceanFlowerClient(fl.client.NumPyClient):
    def __init__(self, data_path, model, epochs=5):
        self.model = model
        self.epochs = epochs
        # Cargar dataset local desde el volumen montado por C2D (/data)
        data = np.load(data_path)
        self.X = torch.tensor(data['x'], dtype=torch.float32)
        self.y = torch.tensor(data['y'], dtype=torch.long)

    def get_parameters(self, config):
        return [val.cpu().numpy() for val in self.model.state_dict().values()]

    def fit(self, parameters, config):
        # Actualizar modelo con los pesos de la ronda recibidos
        state_dict = zip(self.model.state_dict().keys(), parameters)
        self.model.load_state_dict({k: torch.tensor(v) for k, v in state_dict})
        
        # Bucle de entrenamiento local
        criterion = nn.CrossEntropyLoss()
        optimizer = optim.Adam(self.model.parameters(), lr=0.001)
        dataset = torch.utils.data.TensorDataset(self.X, self.y)
        loader = torch.utils.data.DataLoader(dataset, batch_size=32, shuffle=True)
        
        self.model.train()
        for epoch in range(self.epochs):
            for batch_x, batch_y in loader:
                optimizer.zero_grad()
                out = self.model(batch_x)
                loss = criterion(out, batch_y)
                loss.backward()
                optimizer.step()
                
        return self.get_parameters(config={}), len(self.X), {"loss": float(loss.item())}

# 3. Punto de Entrada Principal C2D
if __name__ == "__main__":
    # Rutas estándar de Ocean Compute-to-Data
    INPUT_DIR = "/data/inputs"
    DATA_DIR = "/data/ddo"
    OUTPUT_DIR = "/data/outputs"

    # Cargar pesos globales de la ronda actual desde /inputs (si existen)
    weights_path = os.path.join(INPUT_DIR, "global_weights.npy")
    model = LocalModel()
    
    if os.path.exists(weights_path):
        global_weights = np.load(weights_path, allow_pickle=True)
        state_dict = zip(model.state_dict().keys(), global_weights)
        model.load_state_dict({k: torch.tensor(v) for k, v in state_dict})

    # Cargar el dataset montado por Ocean C2D
    dataset_file = os.path.join(DATA_DIR, "dataset.npz")
    client = OceanFlowerClient(data_path=dataset_file, model=model, epochs=5)
    
    # Ejecutar 1 ronda local de entrenamiento
    updated_weights, num_samples, metrics = client.fit(
        parameters=client.get_parameters(config={}), 
        config={}
    )

    # Guardar los pesos actualizados y métricas en /outputs para que Ocean los recupere
    os.makedirs(OUTPUT_DIR, exist_ok=True)
    np.save(os.path.join(OUTPUT_DIR, "updated_weights.npy"), np.array(updated_weights, dtype=object))
    with open(os.path.join(OUTPUT_DIR, "metrics.json"), "w") as f:
        json.dump({"num_samples": num_samples, "metrics": metrics}, f)
        
    print("✅ Entrenamiento C2D finalizado con éxito. Pesos escritos en /outputs.")
```

## 🐳 Paso 2: El Contenedor Docker C2D (`docker/Dockerfile.c2d`)

Este Dockerfile compila la imagen que Ocean C2D ejecutará en los servidores de los proveedores.

```dockerfile
FROM python:3.10-slim

WORKDIR /app

# Instalar dependencias necesarias
RUN pip install --no-cache-dir \
    numpy \
    torch \
    flwr==1.8.0 \
    pandas

# Copiar el script del cliente
COPY scripts/client_c2d.py /app/client_c2d.py

# Punto de entrada
ENTRYPOINT ["python", "/app/client_c2d.py"]
```

## 🛰️ Paso 3: El Orquestador Federado (`scripts/orchestrator.py`)

Este script se ejecuta en la máquina del investigador u orquestador y utiliza el SDK `ocean.py` para publicar las rondas de entrenamiento en Pontus-X / Ocean.

```python
import time
import json
import numpy as np
from ocean_lib.ocean.ocean import Ocean
from ocean_lib.config import Config

# 1. Configuración del SDK de Ocean Protocol (Pontus-X Devnet o Barge Local)
config = Config(
    network_url="https://rpc.devnet.pontus-x.eu",
    metadata_cache_uri="https://aquarius.devnet.pontus-x.eu",
    provider_url="https://provider.devnet.pontus-x.eu"
)
ocean = Ocean(config)
wallet = ocean.wallet.from_pri_key(os.getenv("PRIVATE_KEY"))

# IDs de los datasets publicados en Pontus-X por cada proveedor
DATASET_DDO_IDS = [
    "did:op:123456789abcdef...nodo_A",
    "did:op:987654321fedcba...nodo_B"
]
ALGORITHM_DDO_ID = "did:op:algo123...flower_c2d_image"

def aggregate_fedavg(local_weights_list):
    """Agregación promedio de pesos de Flower (FedAvg)"""
    new_weights = []
    num_clients = len(local_weights_list)
    for layer_idx in range(len(local_weights_list[0])):
        layer_sum = sum(client[layer_idx] for client in local_weights_list)
        new_weights.append(layer_sum / num_clients)
    return new_weights

# 2. Bucle de Rondas Federadas
ROUNDS = 5
global_weights = None

for r in range(ROUNDS):
    print(f"\n🚀 === INICIANDO RONDA FEDERADA {r+1}/{ROUNDS} ===")
    
    # Guardar pesos globales actuales para enviarlos en los jobs C2D
    if global_weights is not None:
        np.save("global_weights.npy", np.array(global_weights, dtype=object))

    job_ids = []
    
    # A) Iniciar trabajo Compute-to-Data en cada nodo proveedor
    for did in DATASET_DDO_IDS:
        dataset_ddo = ocean.assets.resolve(did)
        algo_ddo = ocean.assets.resolve(ALGORITHM_DDO_ID)
        
        # Pagar tarifa de cómputo con Datatokens y solicitar ejecución
        job_id = ocean.compute.start(
            consumer_wallet=wallet,
            dataset=dataset_ddo,
            algorithm=algo_ddo,
            input_datasets=[] # Opcionalmente adjuntar global_weights.npy
        )
        job_ids.append((did, job_id))
        print(f"  -> C2D Job iniciado en {did[:15]}... ID: {job_id}")

    # B) Esperar la finalización de los trabajos en paralelo
    local_results = []
    for did, j_id in job_ids:
        while True:
            status = ocean.compute.status(did, j_id, wallet)
            if status["status"] == 7: # 7 = Finished en Ocean C2D
                print(f"  ✅ Job {j_id[:10]} en {did[:15]} finalizado.")
                # Descargar los outputs firmados (/outputs/updated_weights.npy)
                output_dir = ocean.compute.download_results(did, j_id, wallet, "./results")
                weights = np.load(f"{output_dir}/updated_weights.npy", allow_pickle=True)
                local_results.append(weights)
                break
            time.sleep(10)

    # C) Agregación Federada (FedAvg) en el Orquestador
    global_weights = aggregate_fedavg(local_results)
    print(f"🎉 Ronda {r+1} completada. Pesos globales actualizados.")

# Guardar modelo final entrenado federadamente
np.save("final_federated_model.npy", np.array(global_weights, dtype=object))
print("\n🏆 ENTRENAMIENTO FEDERADO SOBRE OCEAN C2D FINALIZADO CON ÉXITO.")
```

## 🧪 Cómo Probarlo en Local con `oceanprotocol/barge`

Antes de desplegar en la red **Pontus-X**, puedes probar todo el ciclo en tu máquina local usando el simulador oficial de Ocean Protocol:

1. **Clonar y arrancar Barge (Simulador local de Ocean):**
   ```bash
   git clone https://github.com/oceanprotocol/barge
   cd barge
   ./start_ocean.sh --with-provider2
   ```
2. **Construir la imagen Docker localmente:**
   ```bash
   docker build -t mi-usuario/flower-c2d:v1 -f docker/Dockerfile.c2d .
   ```
3. **Ejecutar el script orquestador:**
   ```bash
   export PRIVATE_KEY=0x... (clave de prueba de Ganache)
   python scripts/orchestrator.py
   ```
